2. Business accounts & role-based access control

An organization is a business account; members hold a role built from permissions. Roles with organization_id = NULL are system templates. platform_admins is a separate, cross-org admin layer. created_by, invited_by reference users (domain 1).

8. Reverse-QR gate entry verification

Ticket-holder scans the gate's rotating on-screen code. uq_entry_attempt_ticket_token blocks replay of the same ticket+token; a partial unique index allows only one approved attempt per ticket.

9. Payments, refunds & payouts

One payment per booking (idempotent on gateway txn id); refunds are a separate ledger to represent partials/retries. Payouts settle organization earnings to a bank account.
